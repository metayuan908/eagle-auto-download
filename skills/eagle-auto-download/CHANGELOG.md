# 版本记录

## 1.6.2 — 2026-10-26

- 对外说明使用通用正文结构描述，不列举工作室名称、官网地址或作者主页；配置由用户按实际目标填写。
- 适配器代码及离线测试保持原有功能，正文与视频指南改用通用文件名并同步内部引用。

## 1.6.1 — 2026-10-26

- 合并 Eagle 文件与元数据的最终验收，复用已回读条目定位原件，哈希后仍重新读取元数据；验收前后核库、每次写入前核库、逐项内容验收与 uncertain 恢复规则保留。
- 视频下载、入队及重复准备共享内容验证回执；每次重新计算当前文件 SHA-256，结合字节数、验证器修订和解码器身份匹配后复用完整解码结果。文件、验证器或回执变化时重新解码，解码期间文件变化则拒绝登记成功。
- 增加 API 各端点请求数、累计耗时、错误数，以及准备阶段视频解码次数、缓存命中与验证耗时。指标只记录端点路径，不保存请求查询参数或正文。
- 相同离线 60 文件样本的 API 请求从 943 次降至 703 次；Adobe 下载至入队的完整解码从 2 次降至 1 次。这是调用量比较，不代表实际耗时同比下降。
- 增加文件变化、验收中切库、哈希后元数据变化、缓存失效和指标统计回归；更新不恢复任务或写入真实 Eagle 库。

## 1.6.0 — 2026-10-26

- 增加 公开 CMS 型 公开 CMS 适配：遍历分页，排除隐藏／删除案例，只采集桌面正文相册和原生视频。
- 增加 Behance 主页分页与公开项目 API 适配，核对作者、项目和模块归属；优先 original/source 图片，保留动图，支持图片集合和正文 Vimeo / Adobe CCV 嵌入。
- Adobe CCV 接入已有外链下载调度、暂停、逐文件回执、缓存对账和准备队列；最高可用播放流无损封装，完整解码与哈希通过后才登记成功。临时签名和播放 Cookie 仅在内存中使用，支持明确配置代理及有限重试。
- 修复空 slug 和同品牌名称前缀导致新案例被误判已收录的问题；新适配站点按准确来源 URL 匹配，人工确认跨站同案后可显式排除项目 URL。
- 增加官方 Eagle 插件的只读诊断工具，读取实时启用清单、拒绝业务及部分失败；记录标签合并旧示例、本地文件来源字段缺口及原生入库保护边界。
- 新功能通过离线正文快照和模拟下载／接口回归验证；更新不写真实 Eagle 库、不恢复任务、不迁移既有队列。

## 1.5.0 — 2026-10-23

- 增加 内容块型 英文站适配器，从 CMS 案例列表发现项目，按正文内容块收集原始图片和原生视频，排除 Up Next、导航与视频海报。
- 保留正文介绍，核对面包屑案例身份，未知内容块停止；支持双图、三图及镜像三图布局，逐文件下载回执与原件哈希缓存。
- 修复本机 Eagle offset 实际为页号时全库对账仅覆盖前 200 条的问题；自动区分页号和条目偏移两种接口行为，重叠或无法确认时停止。
- 新提交返回 ID 后，Eagle 暂时返回 500/503 时在截止时间内继续回读；既有条目对账仍不把服务错误当成不存在，不重复提交。
- 修复品牌名中的裸 & 字符被 HTML 解析器缓冲导致标题为空的问题，显式刷新解析器并保留 CMS 文本名称回退。
- 补充 内容块型 正文边界、原始格式、项目身份、分页兼容、异步回读和下载缓存回归测试。

## 1.4.0 — 2026-10-22

- 文件按已保存 Eagle ID、原件 SHA-256 和项目关联对账，保存提交返回 ID，兼容旧版 success-only 响应；修复跨项目复用被误报 uncertain。
- 增加兼容旧 assets 表的文件身份、项目关联和尝试日志；已有非空状态库首次升级前自动 SQLite backup，保留暂停状态并按资源库绑定队列。
- 共享素材默认进入元数据待审核；可明确选择 preserve_existing 验收复用，保留原条目元数据，各项目简介写入文件夹。
- 修复项目范围预检丢失已导入视频证据；asset-id 精确限定验收目标，未知 ID 或范围冲突立即报错。
- 提交超时与显式重试均落盘，最多一次重提；下载失败用唯一事件 ID 去重，提供显式 --recheck-fallbacks。
- 状态摘要区分唯一文件、项目复用、回退链接、视频替代关系和真实待处理；ready 不再等同完成。
- 每批缓存全库索引、文件夹树和原件指纹，文件夹简介按项目更新；使用真实轮询截止时间，报告耗时与 API 指标。
- 补充真实故障回归场景，整理恢复指南；更新后不自动导出桌面迁移包。

## 1.3.4 — 2026-10-20

- 导入命令支持按 `--asset-id` 限定记录范围，可逐条恢复 uncertain 项，避免单个失败样本阻塞其他待处理素材。

## 1.3.3 — 2026-10-20

- 新增显式 `--retry-uncertain` 恢复路径：默认仍只对账；仅用户明确要求重试时，在全库对账无匹配后对相应条目重提一次。

## 1.3.2 — 2026-10-20

- Eagle 文件条目异步生成时改为只轮询目标项目文件夹，最长等待 30 秒；避免全库分页扫描拖慢回读，并减少大视频刚提交后被误判 `uncertain`。

## 1.3.1 — 2026-10-20

- Eagle 回读对账时忽略其会移除的 ASCII 文件名保留符号（如冒号、斜杠），避免名称因规范化差异导致已导入素材误报 `uncertain`。

## 1.3.0 — 2026-10-20

- 增加可选的 Vimeo 下载失败书签回退：作者关闭下载时立即回退，其他逐条失败达到配置次数后回退；其余素材仍维持文件模式。
- Eagle 书签预览验收支持异步生成：轮询并解码 API 返回路径，必要时调用官方缩略图刷新接口后等待复核；对 `uncertain` 条目只对账，不重复提交。

## 1.2.1 — 2026-10-20

- Eagle 自动移除素材名称中的星号时，导入后的名称匹配与回读验收会按 Eagle 实际保存的清理结果对账，避免视频已写入却被误报为未确认，也避免重复提交。

## 1.2.0 — 2026-10-20

- 文章归档型 适配器保留经校验的 Vimeo 来源播放器地址；Vimeo 公开页不可用时，可在案例页明确嵌入的同一播放器上回退到 yt-dlp。
- 回退仍要求来源 Referer、同一视频 ID、无 DRM、最高可用流及完整文件解码验证；不构造下载地址。

## 1.1.0 — 2026-10-19

- 支持按项目 URL 范围预检、查看导入计划和执行导入，方便逐个审核并分批处理独立项目。
- 范围导入仍完整检查目标项目，并在全状态库范围检查目录重名；未指定范围时保持全量预检行为。

## 1.0.0 — 2026-10-16

首次带版本号的迁移基线；此前开发版本未编号。

- 包含多种官网正文适配器，以及 Vimeo 官方允许下载的视频文件获取流程。
- 强制检查中英文命名、中文简介来源、行业标签、素材归属、外链模式及文件完整性。
- 修复 文章归档型 相关推荐视频混入、大类标签被空值覆盖的问题。
- 保留导入暂停状态，逐项回读验收，失败停止本批；书签与视频文件分别统计。
- 提供带版本号的迁移打包、校验与安装工具，安装前备份旧版，拒绝同版本不同内容及默认降级。
- 附带可在安装目录运行的 64 项回归测试，方便其他电脑修改后验证再迁回。

兼容范围：macOS、Python 3.10+、Eagle 4.0；不包含用户资源库、下载素材、任务状态或定时任务。
